# UniTrack – Student Academic Management System

## 1. Project Description

UniTrack is a web-based Student Academic Management System developed to help students manage their academic information in one convenient platform. The system provides students with easy access to their personal profiles, course information, assignments, academic performance, and weekly timetables.

UniTrack aims to provide a simple and user-friendly platform that helps students organise their academic activities and monitor their academic progress more efficiently.

## 2. Features Included

The system includes the following features:

1. **Login Authentication** – Allows students to access the system using their registered student email and password.
2. **Student Registration** – Allows new users to create an account by providing their personal and login information.
3. **Forgot Password** – Allows users to reset their password using their registered Student ID and email.
4. **Student Dashboard** – Displays an overview of academic information, including CGPA, total courses, pending assignments, and completed assignments.
5. **Student Profile** – Allows students to view and manage their personal and academic information.
6. **My Courses** – Displays current semester courses, course descriptions, lecturer names, and contact information.
7. **My Assignments** – Allows students to view assignments, monitor deadlines, and track assignment completion status.
8. **Weekly Timetable** – Displays the weekly class schedule and provides an option to download or print the timetable.
9. **Academic Performance Chart** – Displays students' academic performance through graphical visualisation.
10. **Assignment Overview Chart** – Provides a visual summary of pending and completed assignments.
11. **Search Function** – Allows users to search for specific courses and assignments.

## 5. Instructions to Run and Test the System

Follow these steps to access and test UniTrack:

1. Open the UniTrack project repository on GitHub or download the project folder.
2. Open the `index.html` file using a web browser, or access the published website through the GitHub Pages link.
3. Enter the demo Student Email and Password provided in Section 3.
4. Click the Sign In button to access the Student Dashboard.
5. Navigate through the sidebar to explore the available pages and features.
6. To test the registration feature, select Create Account on the login page.
7. To test the password reset feature, select Forgot Password on the login page.

**Note:** UniTrack uses browser Local Storage to store demo account information. The system does not use a backend database.
